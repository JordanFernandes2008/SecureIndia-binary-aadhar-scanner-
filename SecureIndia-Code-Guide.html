What happens when someone presses "Scan the web"

  1. The browser (index.html, function run()) sends the text to /api/analyze using fetch.
  2. api/analyze.js checks the text length and the rate limit, then chooses a mode.
  3. If an API key exists, claudeSearch() runs; otherwise keywordSearch() runs.
  4. Keyword mode asks Google News, Bing News and GDELT at the same time, keeps only relevant articles, groups duplicates into stories and decides a verdict.
  5. The server sends back one JSON object: verdict, stories, sources, fact-checks.
  6. The browser's render() turns that JSON into the stamp, tally and story cards.
Say it in the viva"The browser sends the claim to one serverless API. The API searches three news sources in parallel, filters them for relevance, clusters duplicates into stories, scores each story by the credibility of its sources, and returns JSON that the frontend renders."

L76–85Stop-motion animations (keyframes)

@keyframes boil{0%{translate:0 0}33%{translate:.6px -.7px}
                66%{translate:-.7px .4px}100%{translate:0 0}}
@keyframes drop{0%{opacity:0;translate:0 -70px;rotate:calc(var(--r) - 9deg)}

@keyframes slam{0%{opacity:0;scale:2.4}40%{scale:1.3}60%{scale:.9}80%{scale:1.04}100%{scale:1}}

@keyframes draw{to{stroke-dashoffset:0}}

A keyframe lists the poses of an animation. Every animation that uses these runs with steps(1), so it jumps from pose to pose instead of sliding. That jumping is what makes it look like stop-motion.

  • boil: a 3-frame wobble of under 1 pixel, like hand-drawn animation "boiling".
  • drop: a clipping falls onto the desk in 3 frames: in the air, bouncing, then settled at its tilt --r.
  • slam: the stamp comes down big, overshoots, then settles.
  • thud: the desk shakes when the stamp hits.
  • draw: the red string draws itself (a dashed line whose dash offset shrinks to 0).

L1–14Imports, limits, rate limiter

// POST /api/analyze  { "input": "<news text or article link>" }
import { claudeSearch } from '../lib/claudeAnalyze.js';
import { keywordSearch } from '../lib/newsSearch.js';

const MAX_INPUT = 6000;
const hits = new Map(); // best-effort per-instance rate limit

function limited(ip) {
  const now = Date.now(), win = 60_000, max = Number(process.env.RATE_LIMIT_PER_MIN || 6);
  const list = (hits.get(ip) || []).filter(t => now - t < win);
  list.push(now);
  hits.set(ip, list);
  return list.length > max;
}
  • L2–3 bring in the two search engines from the lib folder.
  • L5 sets the maximum input to 6,000 characters.
  • L6 hits is a Map from IP address to a list of request times.
  • L8–14 limited(): take this IP's past request times, keep only those from the last 60 seconds (60_000 ms), add now, and say "limited" if there are more than 6. The limit can be changed with the RATE_LIMIT_PER_MIN setting.

Limitation: the Map lives in one server instance's memory, so the limit is basic, not bulletproof.

export async function claudeSearch(input) {
  const client = new Anthropic();
  const tools = [{ type:'web_search_20260209', name:'web_search', max_uses:8,
                   user_location:{ type:'approximate', country:'IN' } }];
  if (isUrl) tools.push({ type:'web_fetch_20260209', name:'web_fetch', max_uses:3 });
  for (let i = 0; i < 4; i++) {
    msg = await client.beta.messages.create({ model: MODEL, max_tokens: 16000,
      system: SYSTEM, output_config:{ effort:'medium' }, tools, messages,
      betas:['server-side-fallback-2026-07-01'], fallbacks:'default' });
    collectSeenUrls(msg.content, seen);
    if (msg.stop_reason !== 'pause_turn') break;
    messages.push({ role:'assistant', content: msg.content });
  }
  if (msg.stop_reason === 'refusal') throw new Error('The model declined…');
  return { mode:'deep', searchedCount: seen.size, ...keepSeenSources(parseResult(text), seen) };
}

  • The loop handles pause_turn: a long search can pause, so the answer so far is sent back to let it continue, at most 4 rounds.
